How to add or edit a tool

This page reads from a shared Google Sheet. Anyone can add a tool or fix a use case - no code, no developer needed.

  1. Open the shared AI Toolkit Google Sheet (link from your team lead).
  2. Add a row, or edit an existing one. Each row is one tool.
  3. Save. The page picks up changes on the next refresh.

Columns (use these exact headers):

tool Name shown on the card category Grouping label (e.g. "Assistants", "Research", "Decks") roles Comma-separated: Everyone, Account Managers, Copywriters, SEO, PPC tasks Comma-separated task names (these become the headings in "By Task") best One line: what it's genuinely good at cases A few use cases, separated by | (pipe) free yes (leave blank if not free) link URL to open the tool (optional)

PPC team: this is where you add your tools - just fill in rows with the PPC role.
